# God Glorified in Man's Dependence: Modern English glossary

How the Modern English edition renders words that meant something else to Edwards (false friends). The editor's rule (2026-11-16): such a word is replaced with a modern word in the text, chosen by context, never glossed; the sentence and Edwards's voice stay. Scripture quotations (BSB as adjusted) and the Classic are untouched. General rules: `MODERN-ENGLISH-RULES.md`; change list: `work/false-friends-2026-11-16/<book>.md`.

| Edwards | Modern English |
|---|---|
| mere grace, a mere dependence | sheer grace, a pure / sole dependence |
| communication(s), communicated (of God's excellence, of the Spirit) | imparting, imparted |
| owned, own (the doctrines) | acknowledged, profess |
| the happy church | the favored church |
| distinguished (made to differ) | set apart |
| the several persons of the Trinity | each of the persons |
| mind (attend to) | heed |
| sensible of | aware |
| schemes of divinity | schemes of theology |
| arbitrary (grace, good pleasure: God's will alone, unmoved by any excellence) | unconstrained (kept apart from "free", which is Edwards's own word for grace without merit) |
| proper (good, cause) | own; true |
| still (always) | always |
| immediately (wrought: without means) | directly |
| doubtless | certainly |
| humiliation (of the means by which Christ was given) | humbling |
