# Cover fonts

Read by Typst through `./fgb` (`TYPST_FONT_PATHS`), so a build does not
depend on what is installed. Static instances only: Typst ignores variable
fonts.

| font | source | licence |
|---|---|---|
| Cinzel Regular, Bold | github.com/NDISCOVER/Cinzel, `fonts/ttf/` | SIL OFL 1.1 (`OFL.txt`) |
| EB Garamond Regular, Italic, Medium | github.com/octaviopardo/EBGaramond12, `fonts/ttf/` | SIL OFL 1.1, Copyright 2017 The EB Garamond Project Authors |
